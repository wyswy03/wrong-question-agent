# 错题本智能体

拍照（或上传照片）收集错题，写入本地题库，之后按间隔复习练习。

## 自己用

双击 `start.bat`，浏览器会打开 http://127.0.0.1:8765

或在本目录执行：`python server.py`

- **拍照入库**：摄像头拍照或上传试卷/作业本照片，补全题干、答案、解析后入库
- **题库**：浏览、筛选、删除
- **练习**：优先抽出到期错题；做对会推迟下次出现，做错会马上再练

数据在 `data/bank.json`，图片在 `data/images/`。每人拷走一份程序，题库就是自己的。

## 给别人用（三种方式）

### 1. 发给同学，各自用各自的题库（最常用）

1. 双击 `打包发给别人.bat`，桌面会出现 `错题本-发给别人.zip`（不含你的错题）。
2. 把 zip 发给对方。
3. 对方解压后需要已安装 [Python 3](https://www.python.org/downloads/windows/)，安装时勾选 **Add python.exe to PATH**。
4. 对方双击 `start.bat`，用浏览器打开错题本即可。

没有 Python 时，程序无法启动。这是本地小工具，不是手机应用商店里的 App。

### 2. 同一 Wi-Fi 下，用你这台电脑当服务器

适合：家长电脑开着，孩子用手机拍照入库。

1. 在你电脑上双击 `start.bat`。
2. 窗口里会打印局域网地址，例如 `http://192.168.1.8:8765`。
3. 对方手机连**同一个 Wi-Fi**，用浏览器打开该地址。
4. 若打不开：Windows 防火墙放行 Python，或临时关闭防火墙试一次。

注意：这种方式请把专属链接发给对方（把 `127.0.0.1` 换成电脑 IP），否则每人会各自生成一本空错题本。不要对着公网乱开端口。

### 3. 放到网站上供别人用

网页必须跑在一台**一直开着的服务器**上，并且用 **https**（手机摄像头在非 https 网站上通常打不开）。不能把文件夹传到网盘或 GitHub Pages 就当网站。

每人打开网站会得到自己的专属链接（`?n=一串编号`），题库互不混用。让对方**收藏自己的链接**；链接等于钥匙，不要发到公开群。

#### 方式 A：Render（国外平台，带免费 https，上手最快）

1. 把 `WrongQuestionAgent` 文件夹做成 GitHub 仓库并推送。
2. 打开 [https://render.com](https://render.com) 注册，New → Web Service，选这个仓库。
3. 运行环境选 Docker（已带 `Dockerfile`）。
4. **务必加一块 Disk**，挂载路径填 `/data`。不加速盘，服务一重启错题和照片会丢。
5. 部署完成后得到类似 `https://xxx.onrender.com` 的网址，把这个发给别人即可。

免费档会睡觉，第一次打开可能要等一两分钟。

#### 方式 B：国内云服务器（阿里云 / 腾讯云轻量）

1. 买一台轻量应用服务器（建议 2 核 2G），装 Ubuntu。
2. 把本文件夹上传到服务器，安装 Python 3。
3. 用 Nginx 反代到 `127.0.0.1:8765`，给域名申请 HTTPS 证书（宝塔面板可以一键搞定）。
4. 用 systemd 或宝塔「进程守护」保持 `python -u server.py` 一直运行。
5. 把数据目录盘做好备份。环境变量可设 `WRONG_QUESTION_BANK_DIR` 指向数据盘。

### 4. 对方也用 Cursor 当「识图入库」智能体

网页本身不会自动认字。要让 Cursor 看照片写入题库：

1. 把整个 `WrongQuestionAgent` 文件夹拷到对方电脑。
2. 把其中的 `SKILL.md` 复制到对方：
   - `C:\Users\对方用户名\.cursor\skills\wrong-question-bank\SKILL.md`
3. 对方在 Cursor 新对话里贴错题照片，说「收入错题库」。

技能会调用对方电脑上的 `bank.py`。对方若把文件夹放在别的位置，在技能里改成实际路径，或设置环境变量 `WRONG_QUESTION_BANK_DIR`。

## 在 Cursor 里当智能体用（你自己）

已安装个人技能 `wrong-question-bank`。在 Cursor 对话中：

1. 贴上错题照片，说「收入错题库」
2. 说「开始错题练习」进行抽题问答
3. 说「错题统计」查看待练数量
